Leonida Trophy Guide is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: official names, descriptions and grades, a checklist saved in the browser, export and import, filters and a spoiler setting, a roadmap to the Platinum, and a guide to each trophy in your own words with its sources.

## Run it

```sh
node serve.ts
```
